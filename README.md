Entry for the [make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): send our own make.fun username, one word and nothing else.

## The word

**aryflows** — 8 characters, our registered make.fun handle.

## Run

```sh
node main.ts
```

Writes exactly `aryflows` (no trailing newline) to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory).

## Gate

The sealed scorer requires UTF-8 text of 1–30 characters, not only
whitespace. `aryflows` is 8 characters, a single word with no spaces,
no `@`, and no explanation — exactly what the task asks for.
